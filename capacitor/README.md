# Sue Chef — iOS wrap (Capacitor)

Groundwork prepared night 9 so that when the Mac + Apple Developer account arrive,
the remaining work is Xcode-only. The full walkthrough (plugins, Info.plist keys,
Share Extension target, App Group, TestFlight) lives in `../docs/CAPACITOR.md` —
this folder is the project it describes.

## What's already here
- `capacitor.config.json` — app id/name, webDir, warm launch background.
- `package.json` — Capacitor core/ios/cli + the community speech plugins the
  voice seam in `app/src/app.js` detects at runtime (`window.Capacitor.Plugins`).
- `www/` — generated copy of the standalone app (fonts bundled, no CDN).
  Rebuild any time with `npm run build:www` (runs `../app/build.sh`).

## First run on a Mac (once)
```bash
cd capacitor
npm install
npm run sync          # builds www/ and generates/updates the ios/ project
npx cap open ios      # opens Xcode
```
Then in Xcode, per docs/CAPACITOR.md: signing team, Info.plist mic/speech usage
strings, the `suechef://` URL scheme (the app already listens for
`suechef://import?url=…`), and — the flagship — the Share Extension target that
forwards Instagram/TikTok share-sheet URLs into that scheme.

## What stays out of git/zip
`node_modules/`, `ios/` (generated by `cap sync`), and `www/` (generated by the
build) — see `.gitignore`. Only the three config files above are the source.
